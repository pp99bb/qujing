# 取经小英雄

给小朋友复习学而思（人文 / 思维）的西游记闯关答题游戏。iPad 上打开就能玩，第一次打开后断网也能玩。

- 孩子玩：打开网站首页，在 Safari 里点“分享 → 添加到主屏幕”，以后从桌面图标打开。
- 家长中心：在游戏首页右下角**长按“家长”1 秒多**进入（单独的页面 `parent.html`），可以导入题目、改题、看学习报告、调设置、备份。
- 数据只存在这台设备上。换设备或清理 Safari 之前，先在家长中心“备份 / 换设备”里导出备份文件。

文件说明：`index.html` 孩子端，`parent.html` 家长端，`game.js` / `style.css` 游戏本体，`bank.json` 内置题库，`sw.js` 离线缓存。
